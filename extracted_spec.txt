Echo Nullity: Causal Code Tomography Engine

Complete Project Specification, Architecture, Algorithms, Product Design, Safety Model, Research Roadmap, and Implementation Plan

Executive Summary

Echo Nullity is a local-first static analysis and developer tooling system designed to detect semantically vacuous yet executable code, especially in AI-generated software. Unlike traditional linters, dead-code analyzers, or profilers, Echo Nullity measures causal necessity: whether a line of code actually constrains the program’s output state. The project introduces several novel concepts including Causal Luminance, Semantic Tension Mapping, Ghost Code visualization, Causal Provenance Replay, Differential Mutation Verification, and repository-scale semantic tomography.

Project Vision

Create a new category of developer tooling that reveals code which is syntactically valid, executed, tested, and still unnecessary. Echo Nullity acts as an MRI scanner for software semantics.

Emerging Engineering Problem

Modern engineers increasingly rely on AI systems to generate code. AI-generated code often contains identity operations, redundant checks, vacuous error handling, duplicated semantic patterns, and over-engineered abstractions that pass tests but add maintenance cost, cognitive load, and performance overhead.

Novel Concepts

Causal Luminance: Per-line measure of logical necessity.

Ghost Code: Reachable code with zero causal impact.

Semantic Tension Mapping: Cross-function causal equivalence detection.

Causal Provenance Replay: Minimal explanation chain proving necessity or nullity.

Causal Entropy: Measure of how much a function constrains the output state space.

User Experience

Safe Remove Feature

Safe Remove performs verified, reversible semantic surgery on a live codebase.

Preview removal as a unified diff.

Run static dependency checks.

Run side-effect audit.

Run differential execution in a sandbox.

Run performance sanity checks.

Apply patch only after verification passes.

Store rollback snapshot automatically.

Patch Generation

Patches are generated from AST node transformations, not text replacement, to preserve syntax and formatting.

--- a/cart.py+++ b/cart.py@@- temp = price * 1- temp = temp + 0  return price

Rollback Model

Before applying any patch, Echo Nullity creates a Git stash or a local compressed snapshot. Rollback restores the exact previous state and refreshes editor decorations.

Core Algorithms

Causal Luminance

Compute path conditions for each basic block and estimate how easily those conditions collapse under input mutations. Lines with zero state influence receive luminance 0.0.

Semantic Tension Mapping

Normalize ASTs by removing identifiers and literals, flatten decision structures, compute tree edit distance, and derive a causal equivalence score between functions.

Differential Mutation Verification

Temporarily bypass candidate code, rerun tests in an isolated sandbox, and compare observable program state.

Additional Research-Grade Additions

Research Abstract

This work presents Echo Nullity, a local-first causal code tomography engine for detecting semantically vacuous yet executable code in AI-generated software systems. The project introduces Causal Luminance, a per-line logical necessity metric, and Semantic Tension Mapping, a cross-function causal equivalence framework that exposes structurally divergent but behaviorally redundant logic. Unlike traditional static analyzers, Echo Nullity measures causal leverage over program outputs rather than syntactic correctness or reachability. The system combines Tree-sitter parsing, control/data-flow analysis, differential mutation verification, provenance replay, and interactive IDE visualizations. The expected outcome is a substantial reduction in AI-generated code bloat while preserving functional behavior, enabling safer human-AI collaborative software development.

Limitations and Threats to Validity

Reflection and dynamic code generation may evade static analysis.

Native extensions and FFI boundaries are treated as opaque regions.

Incomplete test suites can produce false-safe removals.

Concurrency side effects are difficult to model precisely.

External service contracts may introduce hidden semantic dependencies.

Tree canonicalization may over-approximate equivalence for some language constructs.

Ethical and Privacy Considerations

Echo Nullity is designed as a local-first tool. Source code never leaves the developer machine, no telemetry is collected by default, and all verification occurs in local sandboxes. The system must not automatically modify repositories without explicit user consent.
